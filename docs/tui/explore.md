## Things to try

<div class="tx-tries" markdown>

- ++j++ ++k++ move the cursor
- ++tab++ switch pane
- ++n++ next problem
- ++slash++ search, try `gps`
- ++a++ ++w++ downgrade a code
- ++a++ ++m++ mute a code
- ++r++ undo your changes
- ++question++ list the keys

</div>
