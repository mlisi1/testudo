# Explore the dashboard

Try the dashboard here, with nothing to install. Click it, then move around with the same keys the real one uses. Point at anything to see what it means and where to read more.

The stack shown is sample data with a few faults in it, so the values don't change as they would on a robot.

## Things to try

| Press | What happens |
|---|---|
| ++j++ / ++k++ | Move through the categories. The topics and details follow |
| ++tab++ | Switch to the topics, then move through them |
| ++n++ | Jump to the next topic with a problem |
| ++slash++ | Search, for example for `gps` |
| ++a++, then ++w++ | Downgrade the highlighted topic's code to WARN, and watch the verdict change |
| ++a++, then ++m++ | Mute the code |
| ++r++ | Undo your changes on this page |
| ++question++ | List the keys |

When you are ready for the real thing, [install Testudo](../getting-started/index.md) and run it on your stack.
